Bu proje Python ve Tkinter kullanılarak yapılmış görsel bir hesap makinesidir.

## Özellikler
- Karanlık / Aydınlık tema
- Geçmiş görüntüleme ve silme
- Yüzde hesaplama
- Tarih farkı hesaplama
