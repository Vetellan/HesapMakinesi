# HesapMakinesi
Yazılıma başladım 5. gündeyim. Bunu ChatGPT yardımı ile yaptım. İçinde tema değişme ayarı, iki tarih arası gün farkı hesaplayıcı ve % hesaplayıcı mevcut. 
Nerdeyse tüm günümü aldı çünkü ChatGPT bir ayarı eklerken diğer ikisini bozdu sürekli. 
Tarihi eliniz ile girebilirsiniz diğer türlü 99' u 2099 olarak algılayabilir.
Bunu ilk GitHub projemi yüklemek ve yazılan kodu .exe olarak çıktı almayı deneyimlemek için yaptım.
